# Technology Stack

## Frontend (mvp/)
- **Framework**: React 18 + TypeScript + Vite
- **Styling**: Tailwind CSS with Avalanche Brand Guidelines
- **State Management**: React Query (@tanstack/react-query)
- **Wallet Connection**: WalletConnect/AppKit (@reown/appkit)
- **Blockchain**: Avalanche Fuji Testnet
- **Privacy Technology**: eERC SDK (@avalabs/eerc-sdk)
- **Zero-Knowledge**: Circom circuits, Baby JubJub curves
- **UI Libraries**: Framer Motion, React Icons, React Toastify
- **3D Visualization**: React Three Fiber

## Mobile (mvp-mobile/)
- **Framework**: React Native + Expo (SDK 53)
- **Navigation**: Expo Router + React Navigation
- **Development**: TypeScript + ESLint

## Backend/Smart Contracts (eerc-backend-converter/)
- **Smart Contracts**: Solidity + Hardhat
- **Testing**: Hardhat + Chai + ZKit
- **Zero-Knowledge**: Circom + poseidon-lite
- **Tools**: OpenZeppelin contracts, TypeChain, Solhint
